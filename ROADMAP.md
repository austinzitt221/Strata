# ROADMAP — STRATA

## Build 1 — Core carve/place (CURRENT)
Superflat rock world + bedrock. Drills + dispensers, all 5 tiers, sphere/cube brushes, grid snap, fly, 40-slot inventory, main menu, world list with seeds, save/load. See CLAUDE.md "Definition of done."

## Build 2 — World feel
- Ore veins embedded in rock (SDF material regions from seed): iron, ruby, obsidian, diamond. Mined material enters inventory by volume removed.
- Real terrain generator: heightfield + 3D noise caves, driven by seed. Multiple environments/biomes.
- Basic crafting recipes behind Q (drill/dispenser tier progression crafted from mined ore).

## Build 3 — Survival layer
- Creative/survival mode toggle at world creation.
- Health, fall damage, hunger or equivalent.
- Enemies + animals with spawning rules; guns.
- Day/night cycle.

## Build 4 — Content
- Structures, caves with features, bosses, endgame.
- Options menu expansion, audio (Web Audio, procedural where possible).

Rule: no phase starts until the previous phase's mechanics feel right in playtest.
